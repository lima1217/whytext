# WhyText 界面规范

所有界面修改以这份规范为准。改规范要先改这里，再改代码。审计脚本：`python3 scripts/ux-audit.py`。

## 1. 术语与动词

同一个概念、同一个动作，在全产品只用一个词。中文以 macOS 简体中文系统用语为准，其他语言以 Apple 本地化术语表（Apple Localization Glossaries）里 macOS 的对应词为准。

| 概念 | 简中 | 繁中 | English | 日本語 | 한국어 | 依据 |
|---|---|---|---|---|---|---|
| Keychain | 钥匙串 | 鑰匙圈 | Keychain | キーチェーン | 키체인 | macOS「钥匙串访问」 |
| Accessibility | 辅助功能 | 輔助使用 | Accessibility | アクセシビリティ | 손쉬운 사용 | 系统设置 › 隐私与安全性 |
| Screen Recording | 屏幕与系统录音 | 螢幕與系統錄音 | Screen & System Audio Recording | 画面収録とシステムオーディオ録音 | 화면 및 시스템 오디오 녹음 | macOS 15 系统设置 |
| Login Items | 登录项 | 登入項目 | Login Items | ログイン項目 | 로그인 항목 | 系统设置 › 通用 |
| Provider | 服务商 | 服務商 | Provider | プロバイダ | 제공자 | 产品自有 |
| Base URL | 接口地址 | 介面位址 | Base URL | ベース URL | 기본 URL | 中文用户不认识 Base URL |
| API Key | API Key | API Key | API key（句中）/ API Key（标题式） | API キー | API 키 | 各语言开发者文档的常见写法 |
| Model | 模型 | 模型 | Model | モデル | 모델 | — |

| 动作 | 简中 | 用在 | 不用 |
|---|---|---|---|
| 清掉一整类记录 | 清除 | 清除记录、清除阅读记忆 | 清空、删除 |
| 去掉列表里的一项 | 移除 | 移除服务商、从术语表移除 | 删除 |
| 打开系统设置某页 | 打开系统设置 | 所有跳转系统设置的按钮 | 前往、去设置 |
| 检查 / 安装更新 | 检查更新 / 安装更新 | 更新页、菜单 | 立即检查、立即更新 |
| 验证服务商配置 | 测试连接 | 服务商页 | 测试连通性 |

- 动词不催促：不用「立即」「马上」「赶快」。
- 标点：中文用全角标点，引用界面元素用「」；英文用 “ ”；日文用「」。路径用 ›（English 用 →，与 Apple 支持文档一致）。
- 中文与英文、数字之间留一个半角空格（由 `CJKLatinSpacer` 统一处理模型输出；界面文案手写时同样遵守）。
- 句末：完整句子带句号；按钮、标签、标题、短状态不带句号。
- 中间点 `·` 不用于连接界面文案。

## 2. 文案取舍

- 能用界面本身说清楚的不写说明。每条说明文案回答一个问题：去掉它，用户会卡住吗？不会就删。
- 说明只写「接下来做什么」，不写原理。
- 多语言以最长的那条为准排版：可以改写，不缩小字号、不截断。

## 3. 字号

每个界面最多 4 种字号（不含用户可调的译文正文）。

| 级别 | 字号 / 字重 | 行高 | 用途 |
|---|---|---|---|
| 标题 | 15 semibold | 系统默认 | 设置页标题 |
| 正文 | 13 regular / medium | 系统默认 | 表单行、按钮、面板 UI |
| 说明 | 12 regular | 系统默认 | 行下说明、状态 |
| 辅助 | 11 regular / medium | 系统默认 | 面板标题栏标签、原文预览、诊断报告 |

- 译文正文：13–24pt，用户可调；行高约 1.55，段距约 0.28 倍字号（`MarkdownRenderer`）。
- 斜体：只用于渲染模型输出里的 Markdown 强调，界面文案不用。
- 等宽：只用于接口地址、模型名、API Key、提示词模板、诊断报告、模型输出里的代码。数字列用 `monospacedDigit()`，不是等宽字体。
- 全大写：不用。

## 4. 颜色

- 每个界面只有一个强调色，用于：选中、开关、主按钮、需要处理的提示点、星标和固定的激活态。
- 强调色：**黛绿**（浅色 `#426666`，深色 **铜绿** `#549688`）；作为文字放在深色表单行上时用 **天水碧** `#5AA4AE`（`accentText`），对比度 5.0:1。出处：中国传统色（《色谱》，中国科学院科技情报编委会名词室，1957）。
  对比度：白字在黛绿上 6.3:1；黛绿在浅色窗口上 5.4:1；铜绿在深色窗口上 4.8:1。
- 状态色只在出错时用红色，而且只用在小图标上，不做大面积红底。
- 「已就绪」用次要文字色加对勾，不用绿色胶囊；「需要处理」用强调色。
- 灰色全部偏暖（R > G > B）。

| Token | 浅色 | 深色 | 在窗口底色上的对比度 |
|---|---|---|---|
| textPrimary | `#1D1B18` | `#F4F1EC` | ≥ 13 |
| textSecondary | `#66625C` | `#ADA79F` | ≥ 4.5 |
| textDisabled | `#A39E96` | `#5A5650` | 只用于禁用态（WCAG 豁免） |
| border | `#E8E4DE` | `#FFFFFF1A` | — |
| borderEmphasized | `#D3CEC6` | `#57534D` | — |

## 5. 形状与层次

- 圆角四档：4（内）、8（控件）、12（容器）、窗口由系统决定。
- 嵌套圆角同心：内圆角 = 外圆角 − 间距（`Radius.concentric`）。
- 间距以 4 为单位，少数 2 / 6 / 10 / 14 用于控件内部微调。
- 界面默认是平的。阴影只给真正浮在其他应用上方的窗口（浮动面板、选中气泡），由窗口 `hasShadow` 提供。
- 卡片不套卡片。
- 动画：出现用 `AstryxMotion.present`，状态切换用 `smooth`；开启「减弱动态效果」时只保留淡入淡出。

## 6. 数字

- 一律用系统格式化器：计数 `formatted()`，百分比 `formatted(.percent)`，日期 `formatted(date:time:)`，相对时间 `RelativeDateTimeFormatter`，文件大小 `ByteCountFormatter`。
- 每个数字写清楚它指什么、单位是什么。
- 字符数按字素簇（`String.count`）计算，与用户看到的字一致。

## 7. 确认与撤销

- 能撤销或很容易恢复的操作，直接执行。
- 删不回来、而且丢的是用户自己写的东西，才确认：移除服务商（连同 Key）、清除阅读记忆、提示词恢复默认。
- 确认框写清楚会失去什么；确认按钮用动作本身的动词（「移除」「清除」「恢复」）。
- 危险操作不用大面积红色；系统确认框的破坏性按钮样式由系统决定。

## 8. 规则与平台惯例冲突的取舍

| 项 | 规则 | 平台惯例 | 现状 |
|---|---|---|---|
| 设置侧边栏的彩色图标底色 | 一页一个强调色 | macOS 系统设置用彩色图标 | 已定（2026-11-07）：方案 C，去掉底色，图标用次要文字色，选中行图标为白色 |
| 设置侧边栏材质 | 不用毛玻璃 | macOS 侧边栏默认半透明 | 已定（2026-11-07）：暖灰平面 `sidebarBackground`（#EFECE7 / #262421） |
| 浮动面板 / 气泡材质 | 不用毛玻璃 | 浮层（popover、HUD）默认用材质 | 保留，待定 |
