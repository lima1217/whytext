## 不可逆操作

| 操作 | 位置 | 基线处理 | 处理方式 |
|---|---|---|---|
| 删除服务商（Key 一起删除） | 服务商「−」 | 无确认 | 确认 |
| 清除阅读记忆 | 阅读记忆 | 确认（红色破坏性按钮） | 保留确认 |
| 提示词恢复默认 | 提示词 | 无确认 | 改过时确认 |
| 关闭「保存最近的翻译和解释」 | 通用 | 静默删除全部记录 | 不再删除 |
| 清除最近记录 | 通用 / 菜单 | 无确认 | 保留（只是缓存，阅读记忆里另有完整记录） |
| 从术语表移除单个词 | 阅读记忆 / 面板星标 | 无确认 | 保留（再点一次星标就能加回） |
| 清除 API Key | 服务商 | 无确认 | 保留（Key 可以从服务商后台重新复制） |

## 设计规范现值

- 字号：10（未用）、11、12、13、14（未用）、15；正文 13–24 由用户调。
- 圆角：4 / 8 / 12 / 24 / 28，面板卡片 10，气泡 12（= 8 + 4，同心）。
