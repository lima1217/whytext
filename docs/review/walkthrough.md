# 主链路走查（认知走查 + Nielsen 启发式）

日期：2026-11-07　基线：`852f7fd`
方法：以第一次用 Mac 翻译工具、不懂 API 的用户身份，从「下载后双击打开」走到「第一次拿到译文」，再走追问、换语言、回看记录。每一步问四个问题：
**Q1** 知道下一步要做什么吗？**Q2** 看得到入口吗？**Q3** 看得懂入口和目标的关系吗？**Q4** 做完知道成功了吗？

严重程度：4 = 无法完成主链路，3 = 大多数人会卡住，2 = 会犹豫或走弯路，1 = 打磨项，0 = 不是问题。
启发式编号：H1 状态可见 · H2 贴近用户语言 · H3 用户可控 · H4 一致 · H5 防错 · H6 识别优于回忆 · H8 简洁 · H9 帮助从错误恢复 · H10 帮助文档。

## 视觉

见 `docs/review/inventory.md` 和 `audit-before.txt`。要点：
- 灰色全部是中性灰（R = B），没有一个偏暖；浅色模式次要文字 `#737373` 在窗口底色上只有 4.01:1，低于 4.5。
- 强调色跟随系统（默认亮蓝 `#007AFF`）；同一页里同时出现绿色「已授权」胶囊、黄色「需要」胶囊、蓝色选中行、红橙蓝三色提示点、八种颜色的侧边栏图标。
- 字号：设置页 4 种（11 / 12 / 13 / 15），浮动面板 3 种 UI 字号 + 用户可调正文，都在上限内。
- 斜体只出现在 Markdown 渲染（模型输出的 `*强调*`），等宽只用于接口地址、模型名、Key、提示词和代码，都有理由。
